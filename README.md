# 혈마 키우기

혈교의 꼬마가 무림을, 이계를, 신까지 집어삼킨다. — 방치형 성장 게임 (웹 → 나중에 앱)

## 지금 판: 1판 (0.1.1)
- 자동 전투 · 층 (한 층 10마리, 10층마다 보스 30초) · 쓰러지거나 보스를 못 잡으면 한 층 아래 → "⏫ 다시 도전"
- 강화 6가지 (공격력·체력·방어력·공격 속도·치명 확률·치명 피해) · ×1 / ×10 / 최대 · 꾹 누르면 계속
- 스킬 2개: 🩸 혈살참 (공격력 8배, 10초) · 🛡 호신강기 (3초 무적 + 체력 30%, 20초) · 각각 "자동" 켜기
- 레벨업 카드 3장 중 1장 (정파 무공 / 혈공, 일반·희귀·영웅·전설 21장) · 조합: 출혈 카드 3장 → 💥 출혈 폭발
- 📋 능력치 창 (강화 칸 위 단추 또는 혈마를 톡) · ❓ 게임 설명 (강화 칸 위 · ⚙ 설정) · 📚 카드 도감 (카드 칸, 얻은 카드는 밝게)
- 방치 보상: 꺼 둔 동안 최대 8시간 · 📺 광고 보고 2배 (지금은 가짜 광고 3초)
- 무대 1 혈교 수련장 (50층 혈교 교주, 앞뒤 대사 · 건너뛰기)
- 저장: 폰 안에 저절로 + ⚙ 설정의 백업 코드 내보내기/불러오기

## 폰에서 하는 법
1. 폰 크롬에서 https://mong122.github.io/hyeolma/ 열기
2. 오른쪽 위 ⋮ → "홈 화면에 추가" (또는 "앱 설치")
3. 홈 화면 아이콘으로 켜면 앱처럼 꽉 찬 화면

## 파일
- `index.html` · `style.css` — 화면
- `js/data.js` — 숫자·카드·몬스터 (게임 빠르기는 맨 위 `HM.B` 만 고치면 됨)
- `js/core.js` — 게임 규칙 · `js/ui.js` — 화면 그리기·누르기
- `sw.js` · `manifest.webmanifest` · `icons/` — 홈 화면 앱용
